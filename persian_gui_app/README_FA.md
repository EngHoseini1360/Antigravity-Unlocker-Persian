# رابط کاربری گرافیکی فارسی Antigravity Unlocker (تحت ویندوز)

یک نرم‌افزار دسکتاپ مدرن، زیبا و کاملاً فارسی بر پایه **Python** و **PyQt6** با طراحی به سبک **Fluent / Windows 11 Dark Mode** جهت دور زدن محدودیت‌های منطقه‌ای و رفع خطای ۴۰۰ («User location is not supported») در سرویس‌های هوش مصنوعی **Antigravity 2.0**، **Antigravity IDE** و ابزار خط فرمان **agy CLI**.

---

## ✨ امکانات و قابلیت‌های کلیدی

1. **طراحی زیبا و کاملاً فارسی (RTL Native):**
   - پشتیبانی استاندارد از چیدمان راست‌به‌چپ (Right-to-Left).
   - تایپوگرافی تمیز با فونت‌های استاندارد فارسی (`Segoe UI`, `Tahoma`, `Vazirmatn`).
   - تم تاریک شیک (Dark Glassmorphism) با پالت رنگی هماهنگ با ویندوز ۱۱.
   - کارت‌های اطلاعاتی، نشانگرهای وضعیت نئونی و کلیدهای تاگل انیمیشنی مدرن.

2. **فعال‌سازی هوشمند با یک کلیک (Smart 1-Click Unlock):**
   - پچ خودکار باینری‌های `language_server.exe` و `agy.exe` (تبدیل `ineligible` به `inexigible`).
   - تغییر متغیر محیطی پراکسی به `AG_LS_PROXY` به صورت ایزوله، بدون ایجاد اختلال در سایر نرم‌افزارهای ویندوز یا Git.
   - امکان بازگردانی کامل و ۱۰۰٪ به حالت اولیه (Rollback / Unpatch) با یک کلیک.

3. **اسکن و مدیریت چندگانه نسخه‌ها (Multi-Install Detection):**
   - تشخیص خودکار نسخه‌های نصب‌شده Antigravity 2.0، Antigravity IDE و CLI.
   - نمایش وضعیت دقیق پچ هر فایل اجرایی، اندازه فایل و مسیر نصب.
   - قابلیت افزودن پوشه نصب دلخواه و دستی.

4. **کلیدساز آنی و مدیریت لایسنس (Instant License Key Generator):**
   - تولید رایگان و آنی کلید فعال‌سازی ۲۴ کاراکتری معتبر بر اساس الگوریتم SHA256 نسخه ۲.۲۴.۰.
   - اعتبارسنجی زنده و نمایش فرمت استاندارد.

5. **تنظیمات شبکه و تست زنده پینگ (Network & Live Ping):**
   - امکان تنظیم پروکسی اختصاصی (مثل V2Ray / Clash روی `127.0.0.1:10808`).
   - تست پینگ زنده به سرور `cloudcode-pa.googleapis.com` گوگل.
   - بررسی وضعیت قوانین تفکیک دامنه ویندوز (NRPT).

6. **ژورنال رخدادها و لاگ‌های زنده (Live Diagnostics):**
   - نمایش لاگ‌های سرویس رله (`forwarder.log`) و نگهبان خودکار (`watchdog.log`).
   - کپی گزارش تشخیصی کامل جهت ارائه به پشتیبانی.

## 🚀 نحوه اجرا

### پیش‌نیازها:
- پایتون نسخه ۳.۱۰ یا بالاتر (در این سیستم پایتون 3.15 و PyQt6 نصب است).
- در صورت نیاز به نصب کتابخانه PyQt6:
  ```bash
  pip install PyQt6
  ```

### روش‌های اجرا:
- **روش اول (سریع):** دوبار کلیک روی فایل `run_persian_gui.bat`.
- **روش دوم (با دسترسی ادمین):** راست‌کلیک روی `run_persian_gui_admin.bat` و انتخاب Run as administrator.
- **روش سوم (از طریق ترمینال):**
  ```bash
  python persian_gui_app\main.py
  ```
