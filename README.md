## ✨ امکانات و قابلیت‌های کلیدی

1. **طراحی زیبا و کاملاً فارسی (RTL Native):**
   - پشتیبانی استاندارد از چیدمان راست‌به‌چپ (Right-to-Left).
   - تایپوگرافی تمیز با فونت‌های استاندارد فارسی (`Segoe UI`, `Tahoma`, `Vazirmatn`).
   - تم تاریک شیک (Dark Glassmorphism) با پالت رنگی هماهنگ با ویندوز ۱۱، مک‌اواس و توزیع‌های مدرن لینوکس.
   - کارت‌های اطلاعاتی، نشانگرهای وضعیت نئونی و کلیدهای تاگل انیمیشنی مدرن.

2. **فعال‌سازی هوشمند با یک کلیک (Smart 1-Click Unlock):**
   - پچ خودکار باینری‌های `language_server` و `agy` در هر سه پلتفرم ویندوز، مک و لینوکس (تبدیل `ineligible` به `inexigible`).
   - تغییر متغیر محیطی پراکسی به `AG_LS_PROXY` به صورت ایزوله، بدون ایجاد اختلال در سایر نرم‌افزارها یا Git.
   - امکان بازگردانی کامل و ۱۰۰٪ به حالت اولیه (Rollback / Unpatch) با یک کلیک.

3. **اسکن و مدیریت چندگانه نسخه‌ها (Multi-Install Detection):**
   - تشخیص خودکار نسخه‌های نصب‌شده Antigravity 2.0، Antigravity IDE و CLI در ویندوز، پکیج‌های `.app` مک و لینوکس.
   - نمایش وضعیت دقیق پچ هر فایل اجرایی، اندازه فایل و مسیر نصب.
   - قابلیت افزودن پوشه نصب دلخواه و دستی.

4. **کلیدساز آنی و مدیریت لایسنس (Instant License Key Generator):**
   - تولید رایگان و آنی کلید فعال‌سازی ۲۴ کاراکتری معتبر بر اساس الگوریتم SHA256 نسخه ۲.۲۴.۰.
   - اعتبارسنجی زنده و نمایش فرمت استاندارد بدون نیاز به مراجعه به هیچ کانال یا وبسایت خارجی.

5. **تنظیمات شبکه و تست زنده پینگ (Network & Live Ping):**
   - امکان تنظیم پروکسی اختصاصی (مثل V2Ray / Clash روی `127.0.0.1:10808`).
   - تست پینگ زنده به سرور `cloudcode-pa.googleapis.com` گوگل.
   - بررسی وضعیت قوانین تفکیک دامنه ویندوز (NRPT) و روتینگ ایزوله مک و لینوکس.

6. **ژورنال رخدادها و لاگ‌های زنده کاملاً فارسی (Live Diagnostics):**
   - ترجمه و تحلیل لحظه‌ای پیام‌های سیستمی و رله به زبان فارسی روان.
   - نمایش استاندارد و پاکسازی فرمت خروجی لاگ‌ها در محیط برنامه.
   - امکان کپی گزارش تشخیصی کامل جهت ارائه به پشتیبانی.

## 🚀 نحوه اجرا در ویندوز (Windows)

### روش اول: اجرای نسخه کامپایل‌شده (بدون نیاز به نصب پایتون)
کافیست فایل اجرایی تک‌فایل `AntigravityUnlocker_FA.exe` را دانلود کرده و اجرا نمایید (در صورت نیاز به اعمال قوانین تفکیک شبکه، با دسترسی Administrator اجرا شود).

### روش دوم: اجرا از طریق سورس پایتون
1. پیش‌نیازها: نصب پایتون و کتابخانه PyQt6:
   ```bash
   pip install PyQt6
   ```
2. اجرای برنامه با دابل‌کلیک روی فایل `run_persian_gui.bat` یا دستور:
   ```bash
   python persian_gui_app/main.py
   ```

## 🍏 نحوه اجرا در مک‌اواس (macOS)

پروژه به صورت ۱۰۰٪ بومی با هر دو معماری پردازنده‌های **Intel** و چیپ‌های **Apple Silicon (M1/M2/M3/M4)** سازگار است.

### روش اول: اجرای آسان با دوبار کلیک در Finder (توصیه می‌شود)
کافیست در پوشه برنامه روی فایل زیر دوبار کلیک کنید:
```text
run_persian_gui_mac.command
```

### روش دوم: نصب پیش‌نیازها با Homebrew و اجرا
```bash
brew install python pyqt6
python3 persian_gui_app/main.py
```

📖 **برای راهنمای کامل تنظیمات مک و رفع خطاهای امنیتی، [مستندات جامع مک (MAC_GUIDE_FA.md)](MAC_GUIDE_FA.md) را مطالعه کنید.**

## 🐧 نحوه اجرا در لینوکس (Linux)

پروژه به صورت ۱۰۰٪ چندسکویی و هماهنگ با تمامی توزیع‌های لینوکس (Ubuntu, Debian, Fedora, Arch Linux, Manjaro) آماده شده است.

### روش اول: اجرای آسان با اسکریپت لینوکس (توصیه می‌شود)
در محیط ترمینال لینوکس دستورات زیر را وارد کنید:
```bash
chmod +x run_persian_gui.sh
./run_persian_gui.sh
```

### روش دوم: نصب خودکار پیش‌نیازها و ایجاد آیکون در منوی لینوکس
```bash
chmod +x install_linux.sh
./install_linux.sh
```

📖 **برای راهنمای کامل توزیع‌های اوبونتو، آرچ، فدورا و رفع اشکال، [مستندات جامع لینوکس (LINUX_GUIDE_FA.md)](LINUX_GUIDE_FA.md) را مطالعه کنید.**

## 📱 نحوه اجرا و دریافت آپدیت در ترموکس و اندروید (Termux / Debian PRoot)

این نرم‌افزار به صورت کامل با **Debian داخل Termux** (در محیط‌های دسکتاپ XFCE، VNC و Termux:X11 روی گوشی‌های اندروید با پردازنده‌های ARM64) سازگار است.

### ۱. دریافت فوری آخرین آپدیت‌ها در ترموکس:
هر زمان تغییری در مخزن ایجاد شود، در ترمینال دبیان خود داخل پوشه پروژه دستور زیر را بزنید:
```bash
git pull
```

### ۲. نصب پیش‌نیازها در دبیانِ ترموکس:
```bash
apt update && apt install -y python3 python3-pyqt6 git
```

### ۳. اجرای برنامه:
```bash
chmod +x run_persian_gui.sh
./run_persian_gui.sh
```

### 💡 نحوه شناسایی و پچ فایل در ترموکس (معماری پردازنده ARM64):
- برنامه به صورت خودکار فایل‌های باینری پردازنده‌های موبایل (`language_server_linux_arm64` یا `language_server`) را اسکن و پیدا می‌کند.
- همچنین اگر فایل اجرایی در مسیر دلخواهی قرار دارد، کافیست وارد تب **«📁 مدیریت نسخه‌ها و فایل‌ها»** شده و دکمه **«📄 افزودن مستقیم فایل (language_server)»** را بزنید تا فایل باینری را مستقیماً انتخاب کرده و با یک کلیک پچ نمایید.

## 🛡️ نحوه عملکرد فنی پچ
- **پچ باینری Language Server:** عبارت `ineligible` بدون تغییر در طول بایت‌ها یا ساختار باینری (PE در ویندوز / Mach-O در مک / ELF در لینوکس)، به `inexigible` تبدیل می‌شود؛ در نتیجه محدودیت منطقه جغرافیایی از سمت کلاینت حذف شده و اکانت‌های ایرانی بدون ارور ۴۰۰ متصل می‌شوند.
- **تفکیک ترافیک:** با استفاده از متغیر محیطی اختصاصی `AG_LS_PROXY` و قوانین تفکیک شبکه، تنها درخواست‌های مربوط به هوش مصنوعی گوگل از مسیر مشخص‌شده عبور می‌کنند و سرعت اینترنت سراسری، مرورگرها و ابزارهای توسعه دست‌نخورده باقی می‌مانند.
